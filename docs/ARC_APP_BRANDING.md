# ARC-Related Application Branding

## Scope

These choices apply to client-delivered applications in the ARC ecosystem, including ARC Client, Field App, RFID Test App, and local test applications.

They do **not** currently redefine the branding of the core ARC platform or server portal. Treat ARC itself as a separate branding exercise until explicitly requested.

## Visual Direction

- Use a restrained, professional, modern visual language rather than a playful or cartoon-like style.
- Prefer minimalist black-and-white iconography with colour used sparingly and deliberately.
- Each application should have one clear symbol, not a collection of unrelated elements.
- Avoid ticks or checkmarks unless they genuinely communicate a specific action or status.
- Keep symbol geometry, angles, terminal shapes, and line weights consistent across the application family.
- Use the ARC Client relay symbol as the reference weight. Secondary lines may be thinner only when they remain proportionate to that reference.
- Symbols should communicate the application's function clearly without relying on an enclosing app-icon tile inside product interfaces.
- Application icons may use the shared off-white rounded-square tile required by operating systems, but the underlying symbol should stand independently.

## ARC Client Splash Screen

The approved direction is **Precision B — Relay Mark**.

- Display the lightweight standalone double-arrow relay mark without an icon tile or enclosing shape.
- Use Sora as the splash-screen typeface, bundled locally with the application.
- Use an off-white compact panel over a dark, semi-transparent blurred backdrop.
- Keep the panel structured and precise: small `ARC / CLIENT` identifier, generous reserved mark area, fine divider, restrained typography, and a thin ARC-orange progress indicator.
- Primary line: `Powered by ARC`.
- Copyright line: `© BD&R Software 2026`.
- The splash uses fixed ARC application branding and must never inherit tenant or server branding.
- Fade and slightly lift the panel while clearing the backdrop before revealing the main application.

## ARC Client Interface

- The main client interface may inherit tenant branding supplied by the ARC server; this does not apply to the splash screen.
- Match the server portal's sidebar dimensions, spacing, typography, navigation sizing, icons, and branding proportions where practical.
- The main window's custom title bar is visually split: the left segment continues the sidebar colour and the right segment continues the white main content area.
- The System Console uses a full-width custom title bar in the current sidebar colour.
- Keep controls visually consistent with server-provided button colours and shapes.
- Use colour consistently to distinguish server/app inbound and outbound activity.
- Prefer compact, information-dense layouts with clear spacing and strong legibility.

## Family Principle

Every ARC-related application should be recognisably part of one family through consistent geometry, line weight, restraint, typography, and presentation. Each symbol must remain individually meaningful and appropriate to the application's purpose.
